# 🕷️ Spider-Man Multiversos

Projeto desenvolvido durante o curso da **DIO (Digital Innovation One)** com o objetivo de criar uma experiência interativa inspirada no multiverso do Homem-Aranha utilizando **HTML**, **CSS** e **JavaScript**.

O site apresenta diferentes versões do Spider-Man em um carrossel 3D interativo, permitindo ao usuário navegar entre os universos dos personagens através de animações e efeitos visuais.

---

## 🚀 Demonstração

O projeto simula uma experiência visual baseada no conceito de multiverso, onde cada personagem possui seu próprio destaque visual ao interagir com os cards.

---

## 🧩 Funcionalidades

* ✅ Menu de navegação temático
* ✅ Carrossel 3D de personagens
* ✅ Efeito hover com destaque do personagem
* ✅ Alteração dinâmica do background
* ✅ Animações suaves com CSS
* ✅ Controle manual de navegação entre os cards
* ✅ Layout moderno inspirado no universo Spider-Man

---

## 🕸️ Personagens apresentados

* Tobey Maguire
* Tom Holland
* Andrew Garfield

Cada card direciona para páginas específicas contendo conteúdos relacionados a cada versão do personagem.
